📐 Formulación del Modelo de Optimización Lineal Entera (MILP)

1. Variables de Decisión

El modelo decide la cantidad entera a producir de combos y a destinar para venta individual al detal:

  • X₁: Cantidad de Combos Mercado Familiar Esencial a armar
  • X₂: Cantidad de Combos Mercado Desayuno Completo a armar
  • Y₁: Cantidad de Huevos Kikes AA x30 para venta al detal
  • Y₂: Cantidad de Café Sello Rojo 425g para venta al detal
  • Y₃: Cantidad de Harina Pan 1Kg para venta al detal
  • Y₄: Cantidad de Aceite Premier / Medalla de Oro 3Lt para venta al detal
  • Y₅: Cantidad de Azúcar Blanca 2.5Kg para venta al detal

2. Función Objetivo (Maximizar Utilidad Bruta Diaria)

Maximizar el margen de contribución total (Precio de Venta - Costo de Adquisición real):

MAX Z = 13.100·X₁ + 9.300·X₂ + 9.800·Y₁ + 6.990·Y₂ + 1.600·Y₃ + 5.990·Y₄ + 3.100·Y₅

3. Restricciones de Disponibilidad de Inventario en Bodega

El consumo en combos más la venta al detal no puede superar el stock físico disponible en tienda:

• Huevos: 1·X₁ + 1·X₂ + Y₁ ≤ b₁ (Stock actual)
• Café: 1·X₁ + 2·X₂ + Y₂ ≤ b₂ (Stock actual)
• Harina: 2·X₁ + 2·X₂ + Y₃ ≤ b₃ (Stock actual)
• Aceite: 1·X₁ + Y₄ ≤ b₄ (Stock actual)
• Azúcar: 1·X₁ + Y₅ ≤ b₅ (Stock actual)

4. Restricción de Mano de Obra (Tiempo del Administrador)

El armado del Combo Familiar requiere 12 minutos y el Combo Desayuno 8 minutos de dedicación del dueño:

12·X₁ + 8·X₂ ≤ T minutos (Tiempo disponible del Administrador)

5. Restricciones de Demanda Mínima y No Negatividad

Demanda Mínima Obligatoria:
X₁ ≥ 5,   X₂ ≥ 3
Y₁ ≥ 5,   Y₂ ≥ 2,   Y₄ ≥ 2,   Y₃ ≥ 0,   Y₅ ≥ 0
Naturaleza de las Variables:
X₁, X₂, Y₁, Y₂, Y₃, Y₄, Y₅ ∈ ℤ⁺ ∪ {0}
(Todas las cantidades deben ser enteras no negativas)
